Node Graph
==========

Data types used by :meth:`viser.GuiApi.add_node_graph` to describe node types.
See :class:`viser.GuiNodeGraphHandle` for the node graph widget itself,
:class:`viser.NodeGraphActionHandle` for custom context menu entries, and
:class:`viser.NodeGraphNodeEvent` for the event passed to node callbacks.

.. autoclass:: viser.NodePort
